# START-HERE — AgentCraft Application Development Standard

**Canonical onboarding guide for any new AgentCraft application.**

Download [`START-HERE.zip`](./START-HERE.zip) and read the enclosed documents in this order:

1. `AgentCraft_Application_Development_Standard_AADS_v1.2.md` — common architecture, development, UX, deployment and delivery standards.
2. `TOOLKIT_READ_ONLY_CONSUMER_POLICY.md` — mandatory read-only access to AgentCraft-Toolkit and index-based reuse of promoted capabilities.
3. `UNIVERSAL_SECURITY_CLEANUP_AND_SAFE_SESSION_CLOSURE.md` — execute **only after the owner explicitly declares the current development session complete**.

## Rules

- Project-specific requirements and approved design references supplement, but do not silently override, the common standard.
- Do not modify the AgentCraft-Toolkit repository.
- No credentials or tokens should be committed to this public repository or placed in the package.
- Refer to this folder and its ZIP from each new project's kickoff document.

**Version:** AADS v1.2. **Status:** owner review/approval.
