## Legend

- **Current Support:** What the repo already provides (with file:line evidence).
- **Missing Pieces:** What needs to be added.
- **Reuse Path:** The exact existing module/pattern to mirror or extend.
- **Complexity:** `ALREADY_AVAILABLE | MINOR_INTEGRATION | MODERATE_EXTENSION | MAJOR_REARCHITECTURE | UNSAFE_BLOCKED`.
- **Risk:** Architectural / security / operational risk (with mitigation).
- **Estimated Scope:** New files / modified files / new dependencies / new env vars.
- **Recommendation:** Phase assignment (1 = truthfulness & foundations; 2 = conversational home; 3 = projects; 4 = constrained plugins; 5 = real provider test; DEFER = no-go).
- **Evidence:** Exact `file:line` references.
