## Mold Architect
- Intent/sector/time/outcome -> inspect mold registry -> inspect capability registry -> detect gaps -> call Foundry for new sources/connectors -> compose tested mold recipe -> pilot -> temporary investigation -> archive/upgrade.
- `temporary` recipe can execute and be saved without operational maintenance burden; `reusable` saved, `maintained` monitored/version-pinned, `archived` preserved as recipe/history. No duplicate code per domain.
- A new unfamiliar field must **not** be rejected solely for lacking a mold nor silently assigned a fictitious existing mold.

## Dynamic cross-domain composition
Prefer compose existing climate/energy/agri/AI tools for a one-off question over creating permanent micro-domain mold. Specialist analysis method selected by evidence, not domain name only.

## Agent Factory
Central orchestrator resolves whether general analyst sufficient. Generate expert blueprint on demand for narrowly defined tasks requiring specialization (clinical validation, patent interpretation, energy forecasts). Agents are ephemeral runtime workers with least privilege and a bounded task; after completion, persist *recipe and evaluation* (role, prompts, permitted tools, template, model compatibility, tests, outcome, learning notes), terminate runtime. Next request rehydrates recipe with compatibility and security checks. This is the 'phone book for shift workers'.

## Retention decision (not just frequency)
Candidate agent value = repeat demand + economic value + proven improvement over generalist + rarity/expertise + operational maintenance burden, with mandatory evidence and rights/security gates. Numerical weights for this score must be empirically tuned; do not hardcode illustrative threshold as law. Permanently *stored* ≠ always running. Owner approval for promoted maintained agents. Avoid generating agent when general analyst+capability achieves comparable result.

## Swarm optionality
AgentCraft Swarm Engine building blocks may be reused after due diligence for specific bottlenecks. Do not adopt giant multi-agent hierarchy upfront. ToolKit read-only and verified; no production MCP execution merely because tool discovery succeeded.
