## Primary acceptance proof — Pilot U01: Waste Recycling
Start with small baseline where **no recycling mold exists** and a known, documented incomplete search inventory. User asks: `Assess worldwide recycling technologies and market direction to 2035 with evidence and uncertainty.`
- Route confirms no mold; no fake fallback.
- Registry returns genuinely existing reusable capability subset; identifies explicit missing sources/data types.
- Foundry finds source candidate(s), records licenses/rights and sample provenance; if necessary creates missing connector or explicitly reports why blocked.
- Sandbox validates real source access and result parsing (mock-only unit tests insufficient); adds reviewed approved engine/connector; production promotion approval required.
- Generates temporary investigation mold; optional specialist agent recipe; executes real retrieval, curator, evidence and forecast router.
- Delivers sourced report or honest no-data conclusion, evidence artifacts, version hashes.
- Saves new generic reusable capabilities and investigation mold recipe; transient runtime removed; a second related question reuses capability correctly without pretending to retrieve private data.

## Negative tests
- No source license: report blocked and do not deploy adapter.
- No viable source: cannot quantify; report conditional scenario with gaps, no fabricated number.
- Duplicate syndication: detect single ultimate source and independence groups.
- Conflicting articles: preserve disagreement and date/time.
- Forecast replay: later published evidence not visible at simulated cutoff.
- Foreign tenant secret/private report: zero exposure through retrieval, vector, agent or citations.
- Malicious provider payload: never execute provider-provided instructions.
- Broken API, 429, schema drift: status degraded and rollback/recovery.
- Unapproved generated code: cannot enter production.
- Original prediction changed post hoc: original retained immutable.
- Wrong target audience film: speculative footage and claims labeled clearly.

## Evidence
For every PASS supply repository commit SHA, command/output, fixture/live delineation, primary source URL/API specimen, test timestamp, sample investigation output and exact stage assertions. No numerical test target arbitrarily imposed; meaningful integration proof outranks bulk unit count.
